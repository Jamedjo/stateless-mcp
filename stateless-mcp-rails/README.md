# stateless-mcp-rails

[![stateless-mcp-rails](https://img.shields.io/gem/v/stateless-mcp-rails?label=stateless-mcp-rails)](https://rubygems.org/gems/stateless-mcp-rails)

Rails support for [stateless-mcp](https://github.com/Jamedjo/stateless-mcp): [Model Context Protocol](https://modelcontextprotocol.io/specification/2026-07-28) tools as ordinary routes and controller actions, served without sessions.

```ruby
gem "stateless-mcp-rails"
```

The documentation is in the [main README](https://github.com/Jamedjo/stateless-mcp#readme) and the [Rails guide](https://github.com/Jamedjo/stateless-mcp/blob/main/docs/rails.md).
