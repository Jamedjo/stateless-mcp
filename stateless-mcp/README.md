# stateless-mcp

Rack middleware and building blocks for serving [Model Context Protocol](https://modelcontextprotocol.io/specification/2026-07-28) tools without sessions, from any Rack app, Sinatra included.

> **Status:** unreleased. Nothing is on RubyGems yet.

```ruby
gem "stateless-mcp"
```

The documentation is in the [main README](https://github.com/Jamedjo/stateless-mcp#readme), with guides for [plain Rack](https://github.com/Jamedjo/stateless-mcp/blob/main/docs/rack.md) and [Sinatra](https://github.com/Jamedjo/stateless-mcp/blob/main/docs/sinatra.md). Rails apps can use [`stateless-mcp-rails`](https://github.com/Jamedjo/stateless-mcp/tree/main/stateless-mcp-rails) instead.
